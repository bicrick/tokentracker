Introduction

tokentracker adds up every AI token you spend across your coding tools and every computer you use, into one public profile and heatmap you can put on your site.

A small collector runs on your machine, reads the usage your tools already record locally, and uploads only daily totals per tool and model. It's free and open source (MIT).

Installation

Needs Node 22.13 or newer. Works on macOS, Linux and Windows.

npx github:bicrick/tokentracker init

init walks you through setup:

  1. Finds the AI tools on this machine and shows how many tokens it found, before anything is sent.
  2. Lets you choose which tools to track. Detected tools are on by default.
  3. Creates your free account and picks a public handle, or connects an existing account or your own server.
  4. Names this machine, uploads your history, and turns on hourly background sync.

When it finishes you get your profile link, for example tokentracker-nu.vercel.app/u/you.

More computers

Run the same command on each computer and choose Connect an existing account. Paste the key from ~/.config/tokentrack/config.json on your first machine, and give each computer its own name. Totals from every machine add up on your profile.

Connections

Each tool is a connection. By default every connection is Auto: on whenever the tool is found on this machine, so newly installed tools are picked up automatically. 

tokentrack connect

From there you can:

  • Turn tools on or off.
  • Add a custom folder for a tool installed somewhere unusual.
  • Connect Cursor by entering your cursor.com handle.

Background sync

init installs a per-user job that syncs every hour. It needs no admin rights and shows no permission prompts.

OSMechanismLogs
macOSlaunchd agent, hourly and at login~/Library/Logs/tokentrack.log
Linuxsystemd user timer, cron fallback~/.local/state/tokentrack/sync.log
WindowsTask Scheduler, per user%LOCALAPPDATA%\tokentrack\sync.log

The first sync uploads your full history. Later syncs send only the last 7 days. Claude Code deletes transcripts after 30 days by default, so the hourly sync also keeps that history safe.

Turn it off with tokentrack uninstall and back on with tokentrack install.

Privacy

  • Only daily token counts per tool and model leave your machine. Never prompts, code, file paths or API keys.
  • The server rejects any upload that contains anything else.
  • Your key is stored hashed on the server.
  • tokentrack delete-account removes your account and all its data.

See exactly what would be sent:

tokentrack sync --dry
{ "date": "2026-11-17", "source": "opencode", "model": "github-copilot/claude-opus-5.5",
  "input": 381, "output": 138, "reasoning": 63, "cacheRead": 8448, "cacheWrite": 0, "messages": 1 }

Profile

Every account gets a public page at /u/<handle> with your yearly total and heatmap. Cursor usage is added from your public Cursor profile if you connect it.

Embed and API

Fetch your data and render it however you like. The endpoint allows cross-origin requests and is cached at the edge.

const res = await fetch('https://tokentracker-nu.vercel.app/api/activity?handle=you');
const { activityCounts, totals, models } = await res.json();
// activityCounts: [{ date: "2026-11-17", count: 259485947, sources: { cursor: 3853940, opencode: 255632007 } }]

Coming soon: ready-made embeds (image cards for READMEs, a themeable web component, and a small library that does the heatmap maths for custom designs).

Self-hosting

Prefer to keep your data in your own database? Deploy your own server and point init at it.

  1. Deploy the repo to Vercel and add a Neon Postgres database.
  2. Set TOKENTRACK_INGEST_KEYS (comma-separated, openssl rand -hex 24), TOKENTRACK_ACCOUNT, CURSOR_HANDLE and CRON_SECRET.
  3. Run init, choose Connect an existing account, and enter your server URL and one of your keys.

CLI

tokentrack initGuided setup
tokentrack connectChoose tools, add custom folders, connect Cursor
tokentrack syncUpload daily totals now. --dry prints the payload, --full resends all history
tokentrack statusAccount, machine, tools and recent syncs
tokentrack installTurn on background sync
tokentrack uninstallTurn off background sync
tokentrack delete-accountDelete your account and all data

init flags: --hosted --handle <h> [--cursor <h>], --server <url> --key <key>, --device <name>, --reset, --no-install, --yes.

Config file

Stored at ~/.config/tokentrack/config.json. Keep it private: it holds your key.

{
  "server": "https://tokentracker-nu.vercel.app",
  "handle": "you",
  "device": "laptop",
  "connections": {
    "claude-code": { "enabled": "auto" },
    "codex": { "enabled": true, "paths": ["~/work/.codex/sessions"] },
    "cline": { "enabled": false }
  }
}

FAQ

Do you need my API keys?

No. Nothing reads, stores or uploads API keys.

Does it cost anything?

No. tokentracker is free and open source.

Why is cache most of my total?

Agents reread their context every turn, and providers count those reads as tokens. For agentic coding it's normal for 95%+ of tokens to be cache reads.

A tool isn't detected

Run tokentrack connect and add its folder as a custom path, or open an issue.

Sync fails with a certificate error

You're probably behind a corporate proxy. Run with NODE_USE_SYSTEM_CA=1. Background sync sets this automatically.
