tokentracker
Docs GitHub ↗

Your AI token usage, as an API.

Every token you spend in Claude Code, Codex, Cursor and more, on every machine, saved to a repo on your own GitHub and served as one API your agents can query.

npx @bicrick/tokentracker init

Or ask your agent: Install tokentracker for me.

Free and open source. No account: you sign in to GitHub with a code. Node 22.13+ on macOS, Linux or Windows.

Only daily token counts per tool and model are saved, to your repo. Never prompts, code, file paths or keys.

How it works.

      
    
        
  1. 
          1
          Reads your tools, locally.
          
    A small CLI reads the usage logs Claude Code, Codex, OpenCode, Gemini CLI and others already keep, every hour, on every machine. Cursor comes from your public profile.
    
        
    2. 
        
  2. 
          2
          Saves to your GitHub.
          
    Daily totals per tool and model go into a tokentracker-data repo on your GitHub. Plain JSON you own, history kept forever. Delete the repo and it's gone.
    
        
    3. 
        
  3. 
          3
          Answers as an API.
          
    Query /api/v1/users/you with any filter, or read the static JSON your repo publishes to GitHub Pages. No server needed.
    
        
    4. 
      

      
See a real one: github.com/bicrick/tokentracker-data ↗

    


    

      
Usage over time.

      
Group by day, week, month or year, split by tool or model, filter by any range.

      
GET /api/v1/users/bicrick/usage?range=ytd&group=month&split=tool
