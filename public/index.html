tokentracker
Embed Docs GitHub ↗

Track your AI tokens, in one place.

Every token you spend, across all your coding tools and computers. Embed it on your site or query it with an API.

npx github:bicrick/tokentracker init

Free and open source. Needs Node 22.13+ on macOS, Linux or Windows.
