tokentracker
Docs GitHub ↗

Your AI token usage, as an API.

A collector reads every coding tool on every machine you use. One public API answers how many tokens, which models, which tools and which days.

npx github:bicrick/tokentracker init

Free and open source. Needs Node 22.13+ on macOS, Linux or Windows.

Usage over time.

      
Group by day, week, month or year, split by tool or model, filter by any range.

      
GET /api/v1/users/bicrick/usage?range=ytd&group=month&split=tool

      

    


    

      
Every model you've used.

GET /api/v1/users/bicrick/models?range=ytd
