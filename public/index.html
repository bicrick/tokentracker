/ how it works

01

Run init

It finds your local Cursor, Claude Code and OpenCode usage and shows you what it found before anything is sent.

02

Pick where it lives

Free on tokentracker cloud, or on your own server. Self-hosting is one Vercel deploy with a free Postgres database.

03

It syncs itself

An hourly background job keeps your profile current. Run init on each machine and the totals add up.

/ privacy

The collector runs on your machine and uploads only daily token counts per tool and model. Never prompts, code, file paths or API keys. The server rejects any upload with other fields, and tokentrack sync --dry prints the exact payload. This is all of it: 

{
  "device": "laptop",
  "sources": ["opencode", "claude-code"],
  "rows": [
    { "date": "2026-11-17", "source": "opencode", "model": "github-copilot/claude-opus-5.5",
      "input": 381, "output": 138, "reasoning": 63, "cacheRead": 8448, "cacheWrite": 0, "messages": 1 }
  ]
}

Your key is stored hashed. tokentrack delete-account removes everything.

/ commands

tokentrack initguided setup: sign up or connect an existing account
tokentrack sync --dryshow exactly what would be uploaded
tokentrack statusconfig and recent sync logs
tokentrack uninstallstop the hourly sync
tokentrack delete-accountdelete your account and all data
