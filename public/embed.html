styling the web component

      
The component inherits your page's text colour and can be themed with CSS variables or ::part():

      
token-heatmap {
  --tt-cell-0: #f1f5f9;   /* empty day */
  --tt-cell-1: #c7d2fe;
  --tt-cell-2: #a5b4fc;
  --tt-cell-3: #6366f1;
  --tt-cell-4: #3730a3;   /* busiest */
  --tt-gap: 2px;
  --tt-radius: 2px;
  --tt-font: 'Inter', sans-serif;
}
token-heatmap::part(cell):hover { outline: 2px solid hotpink; }
